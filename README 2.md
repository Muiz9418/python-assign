# Day 20 - Build the Snake Game (Part 2)

Day 20 continues directly from Day 19 — same project, same files.
Day 19 builds the `Snake` class and basic movement; Day 20 adds
`Food`, `Scoreboard`, and the collision detection (wall + tail) in
`main.py`.

All the code lives in **day-19/** (snake.py, food.py, scoreboard.py,
main.py) since Angela Yu's course treats this as one continuous
build across the two days rather than two separate projects.

Run it with:
```
python3 ../day-19/main.py
```
